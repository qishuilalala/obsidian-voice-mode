# Code of Conduct / 社区行为准则

This project adopts the core principles of [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) to maintain a respectful, evidence-based, and harassment-free open-source community.

本项目采纳 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 的核心原则，致力于维护专业、理性、彼此尊重的开源协作环境。

## Our Standards / 我们的准则

Encouraged behavior:

- **Focus on facts and reproducibility**: Support bug reports, design discussions, and architectural trade-offs with reproducible steps, real measurements, and environment details rather than personal remarks.
- **Respect different skill levels and locales**: Welcome new contributors and non-native speakers constructively; give and receive code reviews with professionalism.
- **Protect privacy and credentials**: Never post private voice recordings, personal vault contents, API keys, or authentication tokens in public issues, discussions, or pull requests.

鼓励的行为：

- **聚焦事实与可复现证据**：讨论缺陷、架构设计与性能取舍时提供复现步骤、实测数据和运行环境，对事不对人。
- **尊重不同背景与语言习惯**：友善对待新贡献者与跨语种用户，建设性地进行代码评审并坦诚接收反馈。
- **守住隐私与凭证边界**：严禁在公开 Issue、PR 或日志中附带私人语音录音、个人笔记正文、API 密钥或访问令牌。

Unacceptable behavior includes personal attacks, discriminatory or derogatory language, harassment, publishing private information without permission, or deliberately disrupting technical discussions.

不可接受的行为包括人身攻击、歧视或侮辱性言论、骚扰、未经授权公开他人非公开信息，以及持续干扰正常技术协作的行为。

## Enforcement / 执行与反馈

Instances of unacceptable behavior may be reported privately to the repository maintainer (`qishuilalala`) via GitHub private channels. Maintainers reserve the right to edit, hide, or close non-compliant issues, comments, or pull requests and restrict participation when necessary.

For security vulnerabilities, do not open a public issue; follow [SECURITY.md](SECURITY.md).
